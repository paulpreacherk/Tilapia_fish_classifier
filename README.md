Telling Nile tilapia from similar fish matters to buyers, farmers and fisheries officers, 
and it is hard to do by eye. the model was built on a data set of 1,200 community-verified iNaturalist photos covering six species, 
cleaned it, split it by photographer, and trained three models. 
The best score came from ResNet50, with 61.9 percent accuracy. 
MobileNetV2 was put into a web page because it is ten times smaller. 
It reached 46.8 percent accuracy, with a 95 percent range of 38.1 to 55.6 percent, 
and it found Nile tilapia only 38 percent of the time. 
It separates blue tilapia reasonably well, 
but it does not reliably separate the other tilapia species. 
It should not be used to make real decisions yet.
